# 简历项目表述与面试讲述

**推荐项目名：小模型工具调用参数修复与受控蒸馏实验**

> 基于 STAR/OpenRLHF 完成 Qwen3-0.6B 的 CKD→Sim-RL 公开子实验，构建真实父模型草稿驱动的配对 LoRA 修复与 schema/输入保留级联；在固定 590 条训练数据、三随机种子和独立 2500 请求上，将调用参考匹配率从35.8%提升至37.2%，补充预算匹配控制、请求级统计、失败归因与 token 成本审计。
